📌 Hướng dẫn đề xuất tính năng mới

Hệ thống SmartLMS được thiết kế theo kiến trúc Modular Monolith kết hợp Event-Driven (RabbitMQ). Khi các bạn đem file này sang AI khác để prompt (như Cursor/Claude), hãy ghi chú:

  • Nếu đề xuất sửa UI trang của học viên: Chỉnh code React (dùng Tailwind + Mantine). Phải gọi API `/api/...` để lấy data.
  • Nếu đề xuất tính năng cho Admin/Giảng viên: Chỉnh code Razor Pages (`.cshtml`). Dữ liệu lấy trực tiếp bằng `_context.Courses.ToList()`.
  • Nếu đề xuất tính năng mạng xã hội/tương tác/gamification: Đặt ở module Community. Giao tiếp với Core thông qua RabbitMQ Events (ví dụ: `PointEarnedEvent`).
