---
**LƯU Ý GỬI STITCH:**
- **Định dạng:** Vui lòng cung cấp 100% tài nguyên dưới dạng file vector `.SVG` để không bị vỡ hạt trên màn hình 4K. Riêng các ảnh Illustration (76-85) có thể cung cấp thêm bản `.WebP`.
- **Naming Convention:** Hãy lưu tên file chính xác như danh sách trên để tự động chạy Script import vào ASP.NET và React.
- **Stroke/Fill:** Tất cả icon hệ thống (Mục IV, V) nên dùng Stroke (Nét viền) 2px, có thể chuyển sang Fill khi trạng thái Active.
